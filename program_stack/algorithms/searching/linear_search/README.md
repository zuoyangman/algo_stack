# Linear Search

> Scan the array from left to right and return the first matching index.

## Run

From `program_stack/`:

```bash
./scripts/run.sh searching/linear_search java
./scripts/run.sh searching/linear_search cpp
./scripts/run.sh searching/linear_search rust
./scripts/run.sh searching/linear_search go
```

## Public API (aligned across languages)

| Operation | Description |
| --------- | ----------- |
| `search(a, x)` | Return the index of the first `x`, or `-1` if absent. |

## Notes

- Each language demo self-checks a few fixed cases and prints `linear_search: ok`.
